# InnovaHub Portal

Copia independiente basada directamente en la interfaz original de InnovaHub. Mantiene su estética, creación del hub y dashboard, sustituyendo el motor de IA por una biblioteca personal de enlaces a aplicaciones externas.

## Uso local

```bash
npm start
```

Los metadatos se guardan por ahora en `localStorage` bajo `innovahub.portal.state.v1`. La autenticación y la persistencia mediante Google Drive quedan reservadas para la segunda fase.

Los proyectos fuente no se modifican.
